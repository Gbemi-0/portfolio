Personal Project

YouTube Playlist Search

YouTube has no built-in way to search inside a long playlist or Watch Later list.

This bookmarklet auto-scrolls the page in paced steps (to prevent browser overload on playlists with over 1000 videos), then drops in a live search box that filters every loaded video by title or channel name in real time. I built this project to test my AI augmentation skills before completing an AI Fluency certification from Anthropic.

The process: Directed Claude to write and refine the JavaScript, then tested it myself against my own playlists, caught edge cases (huge playlists overloading the browser, timing out), and iterated until major issues were handled. Runs entirely client-side, nothing is sent anywhere.
